Card Types
MCQ — Single correct answer. >> A) after question, choices as * lines. First listed = correct.
Multi — Multiple correct answers. >> A) C) marks positions A and C as correct. Shown as ◉ in counter.
T/F — Statement :: T or :: F

Features
🔍 Search — Search all questions across every exam. Available from home and session screens.
＋ Quick-add — Add a card directly into the current session queue (saved to Firebase).
☰ Question list — Browse all cards in the session. ⎘ Copy exports them as plain text. Filter chips narrow the list to Wrong / Unanswered / Starred.
↩ Back = Undo disable — Pressing Back immediately after disabling a card re-enables it.
×N badge — Shows how many times you've gotten a card wrong across all sessions.
